# ADR 003 — Entropy drain (supplied source)

**Status in source:** "Absolute entropy exhaustion" / the 0.0 invariant.
**Status in this repo:** Preserved as a negative example. Not a repair.

The supplied protocol builds a lookup table of a CRYSTALS-style ring with the Module-LWE error term removed, then iterates a many-to-one map until the Shannon entropy of the state is 0.

ML-KEM (FIPS 203) is hard under Module-LWE because of that error. Deleting it deletes the assumption. A constant state bound into HKDF info does not authenticate the multiplicity operator; it contributes no min-entropy.

Code: `matlab/adr003/execute_entropy_drain_framework.m`. The routine is included so the source tree is complete. Do not use it as a key schedule.
