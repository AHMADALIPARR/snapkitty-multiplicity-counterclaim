# ADR 001 — Rectification notes from the supplied source

**Status in source:** Accepted
**Status in this repo:** Preserved, not adopted. See `docs/COUNTER-PAPER.md` §6.

The supplied markdown records this as a rewrite after "catastrophic algebraic errors" in the QMHES proofs: ascent printed where descent is required, an undischarged Lipschitz constant, and an illegal converse on encodings.

## Revised statements (source text)

**Lemma B.2.** Replace \(F_q(\alpha_j) = (|\alpha_j|, \arg(\alpha_j))\) by the Cartesian embedding \(F'_q(\alpha_j) = (\operatorname{Re}\alpha_j, \operatorname{Im}\alpha_j)\). Then

\[
\|F'_q(\psi)\|_2^2 = \sum_j |\alpha_j|^2 = 1.
\]

**Proposition F.2.** The source first sets the Lipschitz constant to 1 (isometry), then in the second write-up sets it to \(2\sqrt{2}\) via

\[
\|F_q(\psi) - F_q(\phi)\|_2 \le 2\sqrt{2}\,\sqrt{1 - |\langle\psi|\phi\rangle|}.
\]

Those two constants are not the same statement. The MATLAB checks the \(2\sqrt{2}\) form.

**Proposition B.4.** Encoding is redefined as quantization onto a lattice with covering radius \(R\). Contrapositive used in the source: if \(\|\mathcal{M}_1 - \mathcal{M}_2\|_F > 2R\) then the encodings differ. The MATLAB uses a uniform round-to-grid, which is a Voronoi quantizer only for the cubic lattice.

**Theorem C.2.** Sign flipped to descent:

\[
\mathcal{M}_{t+1} = \Pi_{\mathcal{B}}(\mathcal{M}_t - \eta\nabla\mathcal{L}(\mathcal{M}_t, s_t)).
\]

The source then abandons the matrix and sets

\[
P_t = [k_t] P_{t-1} \oplus G \quad\text{on}\quad E(\mathbb{F}_p): y^2 \equiv x^3 + ax + b \pmod p,
\]

with \(k_t\) derived from quantized QBER and load. Hasse's theorem bounds \(|E(\mathbb{F}_p)|\). It does not prove contraction of equation 24.
