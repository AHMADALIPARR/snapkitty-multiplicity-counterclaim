# ADR 002 — Holographic post-quantum reduction

**Owner:** ours
**Supersedes:** the hybrid QKD layer in Ty Van Gelder's QMHES appendix.

The supplied note drops physical QKD and replaces the multiplicity operator by a bifurcation index

\[
S_{t+1} = 2 S_t + \big(H(S_t \,\|\, \mathrm{payload}) \bmod 2\big).
\]

Encryption is replaced by a linear map over an elementary abelian group \(A \cong (\mathbb{F}_p)^n\), implemented as a truncated Vandermonde matrix over \(\mathbb{F}_p\). The MATLAB checks that a square minor has nonzero determinant modulo \(p\).

A deterministic tree index and an invertible linear map over \(\mathbb{F}_7\) are not a post-quantum KEM. Shor's algorithm is irrelevant to a public linear map; there is no secret.
