## Context

ADR 002 left a boundary tensor in \((\mathbb{F}_p)^k\). That tensor still has algebraic entropy. This record is the crystal-drain protocol from the source markdown: map the boundary through a lookup table built like a CRYSTALS ring with the Module-LWE error term removed, and iterate until the Shannon entropy of the state is 0.0.

## Decision

1. Build a dense sub-algebraic lookup table with no error polynomial. The source map is \(i \mapsto \lfloor\sqrt{i}\rfloor\) on \(\mathbb{F}_7\), which is many-to-one.
2. Feed the boundary tensor through the table until entropy is 0.0 or 100 epochs elapse.
3. After each pass, subtract the minimum coefficient so the remaining values sit on a shrinking set.
4. Hold when every coordinate is the same scalar. Shannon entropy of that vector is 0.

## Consequences

ML-KEM (FIPS 203) is a KEM because of the Module-LWE error term. This record deletes that term inside the drain, so the drain is not an encapsulation algorithm and is not a claim against CRYSTALS-Kyber. A constant state bound into HKDF info adds no min-entropy. The data-plane shared secret stays the ML-KEM-1024 secret from his stack. The runner exists so the 0.0 hold condition in the source can be executed and inspected.
