# ADR 002 — Holographic post-quantum reduction via elementary abelian bifurcation

- Status: Accepted
- Date: 2026-10-08
- Owner: ours
- Supersedes: Ty Van Gelder, *QMHES — Mathematical Appendix*, 2026, physical QKD layer and the continuous multiplicity operator \(\mathcal{M}_t\)
- Depends on: ADR 001
- Code: `matlab/adr002/execute_holographic_pq_framework.m`

## Context

His hybrid layer sources key material from a physical QKD adapter (basis exchange, sifting, Toeplitz-hash privacy amplification, QBER monitoring) and from ML-KEM-1024. The multiplicity operator is a real matrix updated by the feedback map in equation 24. ADR 001 removed floating-point drift from that matrix. This record removes the physical channel.

## Decision

Drop physical QKD. Collapse \(\mathcal{M}_t\) to a bifurcation index on an elementary abelian \(p\)-group \(A \cong (\mathbb{F}_p)^n\).

1. Hybrid layer deprecated. No hardware shared secret. Encapsulation stays a post-quantum KEM (ML-KEM-1024), not a fiber or free-space quantum link.
2. Multiplicity becomes a tree index. At epoch \(t\) the state branches on payload parity:

\[
S_{t+1} = 2 S_t + \big(H(S_t \,\|\, \mathrm{payload}) \bmod 2\big).
\]

Consensus is equality of the node index, not convergence of a matrix.

3. Bulk message \(m \in (\mathbb{F}_p)^n\) maps to a boundary tensor \(C \in (\mathbb{F}_p)^k\), \(k > n\), by a matrix over \(\mathbb{F}_p\). The runner uses a truncated Vandermonde over \(\mathbb{F}_7\) and checks that a square minor is invertible.

## Consequences

QBER, Toeplitz privacy amplification, and the QKD key pool leave the protocol. The bifurcation index is a domain separator, not a secret. A public linear map over \(\mathbb{F}_p\) is not a KEM and is not a claim that Shor's algorithm fails against it. Secret-key encapsulation remains ML-KEM-1024. Fault tolerance here is reconstruction from an invertible minor, which the MATLAB checks, not an information-theoretic threshold scheme.
